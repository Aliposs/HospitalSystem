WHAT CHANGED
================================================================================

BEFORE (Problem):
- Admin role was in user_roles table
- Same user_id could be in doctors AND user_roles with role='Admin'
- CONFLICT: One person = Doctor + Admin

AFTER (Solution):
- Admin users have their own admin_users table
- user_roles table only has: Doctor, Patient, Lab
- NO CONFLICT: Each person has ONE clear role

================================================================================
DATABASE STRUCTURE
================================================================================

admin_users (NEW - Separated)
  - user_id → auth.users
  - email
  - full_name
  - account_status
  - Admin users ONLY

user_roles (UPDATED - No Admin)
  - user_id → auth.users
  - role: 'Doctor' | 'Patient' | 'Lab' (NO 'Admin')
  - Doctor/Patient/Lab ONLY

medical_specializations
  - created_by → admin_users.user_id

doctor_specializations
  - assigned_by → admin_users.user_id

audit_logs
  - admin_id → admin_users.user_id
